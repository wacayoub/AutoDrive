AutoDrive 1.14.1 simplifie l’accueil en mode Applications Android.

- Deux raccourcis compacts avec icône et libellé ouvrent Maps et YouTube dans leurs applications Android.
- Le choix de YouTube, y compris ReVanced s’il est installé, se fait dans Settings → Application YouTube. La mise à jour conserve l’application choisie.
- Une application indisponible est indiquée sous son nom. Les boutons Google Play ont été retirés de l’accueil.
- Settings → Affichage Maps / YouTube donne accès au mode Sites web à deux panneaux.

Installe cette mise à jour par-dessus la version précédente pour conserver tes réglages et tes stations. Android affiche sa confirmation habituelle.
